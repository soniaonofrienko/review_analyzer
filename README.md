
# Анализ тональности отзывов

Инструмент для анализа тональности текстовых отзывов из CSV-файла.

## Структура репозитория

(Вам следовало перенести `run_analysis.py` под `src`, а `core.py` завернуть в модуль (папку с `__init__.py`). 
`src` - это способ изолировать основной код, а не просто папка. Мы используем его, чтобы с кодом можно было работать как с python-модулем.)

```
review_analyzer/
├── run_analysis.py
├── requirements.txt
├── README.md
├── .gitignore
├── data/
│   └── sample_reviews.csv
└── src/
    └── core.py
```
## Инструкция по запуску

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   
2. Запустите анализ:
   ```bash
   python run_analysis.py

## Пример результата
```
Статистика тональности:
------------------------------
Positive: 8 (66.7%)
Negative: 3 (25.0%)
Neutral: 1 (8.3%)
```
Результаты в виде текста и csv-файл сохраняются в папку output/.
Также папке output/plots/ создаётся файл sentiment_pie.png с диаграммой.
